# EQ AI Mix Vocals Full (VST3)

ปลั๊กอิน EQ สำหรับมิกซ์เสียงร้อง เขียนด้วย JUCE (C++) — แบรนด์ อาร์ม หนองม่วง มือเปิ่มสตูดิโอ

## ทำงานอย่างไร
1. กด **LEARN** แล้วเล่นเสียงร้อง/พูดจริงผ่านปลั๊กอิน 10–20 วินาที (ตัววิเคราะห์ FFT 2048 จุด เก็บค่าเฉลี่ยสเปกตรัม ข้ามช่วงเงียบ)
2. ปลั๊กอินเทียบสเปกตรัมที่ได้กับเป้าหมายของสไตล์ที่เลือก (Pop / Rap / Rock / Speech) แล้วปรับเกน 6 ย่าน: 120 Hz, 300 Hz, 1 kHz (อ้างอิง), 3.5 kHz, 7 kHz, Air (high shelf 12 kHz) จำกัดไม่เกิน ±6 dB
3. มี High-pass 80 Hz ตายตัว ตัดเสียงอู้ต่ำ

ปุ่มควบคุม: Style, LEARN, AI Amount (0–100%), Air (±6 dB), Output (±12 dB)

> หมายเหตุ: "AI" ในที่นี้คือการวิเคราะห์และปรับค่าอัตโนมัติแบบ adaptive (DSP) ไม่ใช่โครงข่ายประสาทเทียม
> ค่าเป้าหมายต่อสไตล์อยู่ใน `PluginProcessor.cpp` (`styleTarget`) ปรับจูนตามหูได้

## วิธีบิลด์
ต้องมี CMake 3.22+, คอมไพเลอร์ C++17 (Visual Studio 2022 / Xcode / gcc) และอินเทอร์เน็ต (ดึง JUCE อัตโนมัติ)

```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

ไฟล์ `.vst3` จะถูกคัดลอกไปโฟลเดอร์ VST3 ของระบบอัตโนมัติ (Windows: `C:\Program Files\Common Files\VST3`)
และมีเวอร์ชัน Standalone สำหรับทดสอบ

## ใบอนุญาต
JUCE ใช้ได้ฟรีสำหรับโปรเจกต์ที่เผยแพร่แบบ AGPLv3 หรือรายได้ต่ำกว่าเกณฑ์ของ JUCE ถ้าจะขายเชิงพาณิชย์ควรตรวจสอบใบอนุญาต JUCE และ Steinberg VST3 ก่อน
